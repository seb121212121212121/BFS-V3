# **Windows found that this file is potentially harmful Warning FIX**



### **To disable the "Windows found that this file is potentially harmful" warning, follow these steps:**



**Method 1: Adjusting Internet Explorer Security Settings**

---

1. #### **Open Internet Options: Open the Run dialog box (Windows key + R) and type *inetcpl.cpl*, then press Enter. Alternatively, search for "Internet Options" in the Start Menu.** 



#### **2. Go to Security Tab: Select the "Security" tab in the Internet Options window.** 

#### 

#### **3. Customize Settings: Click on the "Custom level..." button.** 

#### 

#### **4. Locate "Launching applications and unsafe files": Scroll down to the "Miscellaneous" section and find the "Launching applications and unsafe files" setting.** 

#### 

#### **5.Enable (Not Secure): Choose "Enable (not secure)" and click "OK".**  

#### 

#### **6.Confirm and Apply: Confirm the change when prompted and apply the settings.** 







### **Method 2: Unblocking Specific Files**



1. ### **Locate the File: Find the file that triggered the warning.**

### 

### **2. Right-click and Properties: Right-click on the file and select "Properties".**

### 

### **3. Unblock the File: In the "General" tab, check the box labelled "Unblock" (if available).**

### 

### **4. Apply Changes: Click "Apply" and then "OK".**
